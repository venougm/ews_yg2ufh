YG2UFH Web Flasher — EWS T-Beam

Flash Firmware EWS ke T-Beam

Pasang firmware EWS ke LilyGO T-Beam v1.2 langsung dari browser — tanpa install Arduino IDE, PlatformIO, atau driver. Cukup kabel USB.

⚠ Browser ini belum tentu mendukung WebSerial. Gunakan Google Chrome atau Microsoft Edge di komputer (bukan HP) agar tombol Install aktif.

🔌 Cara pakai

1
Colok T-Beam ke komputer pakai kabel USBPastikan kabel data (bukan kabel charge-only).
2
Klik tombol Install di bawahBrowser akan menanyakan port serial — pilih port T-Beam (biasanya "CP210x" atau "CH9102").
3
Tunggu proses flashing selesaiJangan cabut USB sampai selesai. Setelah itu T-Beam reboot sendiri.
4
T-Beam jadi WiFi AP EWS-<node> / YG2UFH-EWS-SetupSambungkan HP/laptop ke WiFi itu (sandi 1234567890), buka http://192.168.4.1 untuk setting.
Browser tidak mendukung WebSerial — pakai Chrome/Edge desktop. Flashing hanya bisa lewat HTTPS atau localhost.
✓ Chrome ✓ Edge ✗ Firefox ✗ Safari ✗ HP/Android browser*
*Sebagian Android+Chrome bisa dengan OTG; paling andal pakai komputer.

✅ Setelah flashing

Firmware default boot sebagai Access Point. Langkah setting pertama:

A
Sambung ke WiFi YG2UFH-EWS-Setup (sandi 1234567890)
B
Buka http://192.168.4.1 → form setup
C
Pilih peran (Node/Gateway), wilayah (dropdown), WiFi, MQTT, LoRa, sensor → Simpan & Jalankan
D
Perangkat reboot jadi WiFi client dan mulai kirim data

Catatan: web flasher ini menanam firmware + aset web (SPIFFS) sekaligus bila manifest.json menyertakan image gabungan dengan SPIFFS. Lihat BUILD.md.
