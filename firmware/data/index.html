YG2UFH Setup Perangkat EWS ● Mode AP
📶
Perangkat dalam mode Access Point. Isi form di bawah, lalu tekan Simpan & Jalankan.
Buka http://192.168.4.1 · sandi AP default 1234567890. Setelah disimpan, alat reboot jadi client WiFi dan mulai bekerja.

🧭 Peran Perangkat

▾
Satu firmware, peran dipilih di sini (bukan dari jumper PCB).
📡 NODE
Baca sensor di lapangan, kirim ke gateway via LoRa (atau WiFi bila ada).
🛰️ GATEWAY
Terima LoRa dari node, teruskan ke MQTT internet. Kelola sirine.

🪪 Identitas & Lokasi

▾
node_id harus UNIK se-sistem (prefix kabupaten). Wilayah dipilih dari dropdown bertingkat (bukan ketik bebas) agar tidak ada typo — kabupaten masuk ke topic MQTT. Koordinat diisi manual oleh operator.

🌐 WiFi Internet semua peran

▾
Jaringan internet untuk client mode. GATEWAY wajib; NODE opsional (kalau ada WiFi, node bisa kirim langsung).
Auto-AP fallbackKalau WiFi gagal konek, perangkat kembali jadi AP agar bisa di-setting ulang.

📨 MQTT gateway

▾
Broker server EWS. Data dipublish sebagai JSON ke yg2ufh/ews/<kabupaten>/<node_id>/data.
Aktifkan MQTTPublish ke broker saat ada WiFi.

📻 Radio LoRa semua peran

▾
Parameter harus SAMA di semua perangkat satu jaringan. Board 915 MHz.
"Jauh" = tahan halangan pohon, data rate rendah. Cocok 500 m–1 km.
CAD (cek kanal sebelum kirim)Kurangi tabrakan paket antar node.

🌦️ Sensor Aktif semua peran

▾
Centang sensor yang terpasang. Field JSON hanya dikirim untuk sensor yang aktif.
